================================================================================
                         DEPLOYMENT REQUIREMENTS
================================================================================

Environment Variables Required:

1. MONGODB_URI
   Description: MongoDB connection string
   Example: mongodb+srv://user:pass@cluster.mongodb.net/database

2. STRIPE_SECRET_KEY
   Description: Stripe secret key for server-side operations
   Example: sk_live_xxxxxxxxxxxxxxxxxxxxx

3. STRIPE_PUBLISHABLE_KEY
   Description: Stripe publishable key
   Example: pk_live_xxxxxxxxxxxxxxxxxxxxx

4. NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY
   Description: Public Stripe key (exposed to client)
   Example: pk_live_xxxxxxxxxxxxxxxxxxxxx

All variables must be configured in Vercel project settings.
